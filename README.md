# Palengke Online: the complete NC III front-end practical

A step-by-step tutorial for the TESDA **Web Development (Front-End) NC III** practical assessment. You build a complete website from mockups and a provided REST API (Node.js or PHP + MySQL on XAMPP): a shop with search and filters, log in for customers and sellers, a shopping cart, checkout, order history and a seller dashboard. Then you test it, secure it, speed it up and document it.

**Open `index.html` in a browser to start.** It works offline. **`HOW-TO-RUN.md`** shows how to start the API and the finished website.

## What's in this repository

```
index.html                    the tutorial
HOW-TO-RUN.md                 how to start the API and open the website
practice/palengke/
├── provided/                 what the assessor gives you
│   ├── BRIEF.md              the task
│   ├── API.md                the API document (every endpoint)
│   ├── api.http              test requests for the VS Code REST Client
│   ├── STYLE-GUIDE.md        colours and components
│   ├── mockups/              13 page designs (desktop and phone)
│   ├── api-server/           the REST API in Node.js (start it from VS Code's Run and Debug)
│   └── api-php/              the same REST API in PHP + MySQL, for XAMPP (with database.sql)
└── solution/                 the finished website: HTML, Bootstrap 5, JavaScript, Vue.js 3
    └── docs/                 plan, review, test plan, risk assessment, performance
```
